# 09 V0.1 验收标准

## 数据
- [ ] 2–3 只境内股票型 ETF 指定历史区间可采集且导出。
- [ ] 重复导入幂等、异常定位明确、同样快照的哈希稳定。
- [ ] 日线缺口、复权/分红口径可追踪；不可靠数据不得假装完整。

## 交易
- [ ] 日线因果正确：收盘信号不能在不可实现的同日价格成交。
- [ ] 资金不足、交易单位、T+1、手续费、滑点、不可成交测试通过。
- [ ] 订单意向、实际成交、现金与持仓账可核对。

## 研究
- [ ] 两个基准策略在相同数据和费用设置下可比较。
- [ ] 同一实验在相同版本下重复运行结果一致。
- [ ] 开发/验证/测试区间和研究参数被记录。
- [ ] 至少一次故意注入脏数据和失败订单的测试能检测到问题。

## 报告与工程
- [ ] 产生 JSON 元数据、CSV 交易明细和可读 HTML 报告。
- [ ] 报告声明成本、流动性、复权和其他假设及限制。
- [ ] 单元测试与回归测试通过；敏感信息与历史大数据不入库。
- [ ] README 与 ADR 与实际实现同步更新。

**发布条件**：工程正确即可发布，不要求收益为正，也不声明投资有效性。
