# ADR-005：Codex 与模型 API 双入口

**状态：Accepted（方向）；实际接口待 V0.2 设计**

## 决策
V0.1 用 Codex 辅助开发及交互式研究，不额外购买 AI API，也不实现运行时 Agent。V0.2 可增加受控 Research Tools 与可替换 ModelProvider，供 Codex 和付费 API 共享。

## 安全边界
AI 不直接变更历史行情、不可篡改回测账簿、不可跳过风险检查；无实盘交易权限。模型调用有费用预算、超时和实验版本审计。

## 理由
保持低成本并避免绑定供应商；先确认量化核心正确，再评估 AI 是否产生增量价值。
